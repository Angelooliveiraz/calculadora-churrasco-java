# 🍖 Calculadora de Churrasco

Uma aplicação simples desenvolvida em Java para calcular a quantidade ideal de carne, refrigerante e água para um churrasco, considerando o número de adultos, crianças e a duração do evento.

## 🚀 Objetivo

Este projeto foi criado durante meus estudos de Java com o objetivo de praticar:

* Entrada de dados com `Scanner`
* Estruturas condicionais (`if` e `else if`)
* Operações matemáticas
* Conversão de tipos (`int` e `double`)
* Formatação de saída com `printf`
* Controle de versão com Git e GitHub

## 📋 Funcionalidades

* Calcula a quantidade de carne necessária
* Calcula a quantidade de refrigerante necessária
* Calcula a quantidade de água necessária
* Ajusta automaticamente o consumo conforme a duração do churrasco

    * Mais de 4 horas → +25%
    * Mais de 6 horas → +50%
* Exibe resultados em gramas/ml e também em kg/litros

## 🧮 Regras de Consumo

### Adultos

| Item         | Quantidade |
| ------------ | ---------- |
| Carne        | 400g       |
| Refrigerante | 500ml      |
| Água         | 300ml      |

### Crianças

| Item         | Quantidade |
| ------------ | ---------- |
| Carne        | 200g       |
| Refrigerante | 300ml      |
| Água         | 300ml      |
